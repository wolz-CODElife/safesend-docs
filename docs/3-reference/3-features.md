## SafeSend Features

### Safe Send
Primary interface for creating secure token transfers.

### Transaction History
View completed and pending transfers, including transaction hashes.

### Address Book
Save and reuse recipient addresses to reduce manual entry errors.

### Add Custom Token
Manually add ERC-20 compatible tokens not listed by default.

### Manage Tokens
Enable or disable tokens shown in the Safe Send interface.

### Profile
Manage notifications and external integrations such as Telegram.
