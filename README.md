## SafeSend Documentation

Web3 tool designed to reduce common mistakes when transferring tokens between wallet addresses. SafeSend adds an extra verification step before a transaction is sent, helping users avoid costly errors that cannot be reversed on-chain.

SafeSend helps you confirm intent before execution, whether you are sending token occasionally or handling frenquent transfers.
