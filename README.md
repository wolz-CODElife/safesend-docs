# SafeSend Documentation

SafeSend is a Web3 tool designed to reduce common mistakes when transferring tokens between wallet addresses.

Blockchain transactions are irreversible. SafeSend adds additional verification and confirmation steps before execution, helping users confirm intent and avoid costly errors.

Whether you are making an occasional transfer or handling frequent transactions, SafeSend helps you review, verify, and confirm before funds move on-chain.
